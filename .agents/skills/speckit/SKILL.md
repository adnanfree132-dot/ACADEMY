# GitHub Spec Kit (Spec-Driven Development)

Spec Kit transforms vague ideas into production-ready software through structured, repo-native specifications.

## The Spec-Driven Development (SDD) Lifecycle:

1. **`/speckit-constitution`** — Establish project principles, quality bars, and non-negotiables.
2. **`/speckit-specify <description>`** — Formulate a detailed, technology-agnostic feature spec in `specs/NNN-<feature>/spec.md`.
3. **`/speckit-clarify`** — Detect ambiguities, resolve edge cases, and finalize decisions.
4. **`/speckit-plan`** — Produce technical blueprints, architectural decisions, and contract definitions (`plan.md`).
5. **`/speckit-tasks`** — Break down the technical plan into phased, dependency-ordered tasks (`tasks.md`).
6. **`/speckit-implement`** — Execute task implementation systematically with automated validation.
7. **`/speckit-analyze`** — Audit consistency between specs, plans, tasks, and codebase.
8. **`/speckit-checklist`** — Validate quality criteria and completion readiness.
9. **`/speckit-converge`** — Verify that the final implementation fully matches all requirements.
